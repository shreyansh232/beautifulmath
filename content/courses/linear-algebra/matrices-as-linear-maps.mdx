## First principles

A map $T$ is **linear** if

$$
T(a\mathbf{u} + b\mathbf{v}) = a T(\mathbf{u}) + b T(\mathbf{v})
$$

It respects addition and scaling. No curving, no shifting (translations alone are affine, not linear).

A matrix $A$ represents a linear map via $\mathbf{y} = A\mathbf{x}$.

<MatrixMapDiagram />

Columns of $A$ are where the basis vectors go. That one sentence unlocks most geometric matrix intuition.

## Multiply as weighted combination

$A\mathbf{x}$ is a linear combination of $A$'s columns with weights from $\mathbf{x}$.

## Composition

Doing $B$ then $A$ is the product $AB$ (order matters). Neural nets stack such maps (plus nonlinearities).

## Real world

A 2D rotation matrix turns camera coordinates. A shear matrix models certain simple distortions.

## AI / ML bridge

Weight matrix $W$ learns which linear mixture of features predicts well. Attention and convolutions are structured linear maps with weight sharing.
