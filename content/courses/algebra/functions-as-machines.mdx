## First principles

A **function** $f$ from a set of inputs to outputs assigns **exactly one** output $f(x)$ to each allowed $x$.

<FunctionMachineDiagram />

If one input could yield two different outputs, it is not a function. Vertical-line tests on graphs encode the same idea.

## Examples

- $f(x) = 2x + 1$ (linear)
- $g(x) = x^2$ (each $x$ still has one square; many $x$ share an output)
- Domain matters: $\sqrt{x}$ needs $x \ge 0$ in the reals

## Composition

$(f \circ g)(x) = f(g(x))$: feed $x$ into $g$, then feed that result into $f$. Order usually matters.

## Why this is the gateway to models

A formula is a function. A spreadsheet column computed from another is a function. A trained predictor $\hat{y} = f_w(x)$ is a function whose internal knobs $w$ we choose.

Euler's $f(x)$ notation makes that reusable: name the machine, then apply it.

## Real world

Unit conversion $C = \frac{5}{9}(F - 32)$ is a function from Fahrenheit to Celsius. Invertible here, so you can undo it.

## AI / ML bridge

Layers compose: $f_3(f_2(f_1(x)))$. Backpropagation is the chain rule on that composition. You will meet that formally in calculus intuition.
