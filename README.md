# Beautiful Math

A personal course for rebuilding math foundations from first principles - with real-world links, mathematician vignettes, and honest bridges to AI/ML.

## Tracks

1. **Foundations** - numbers, operations, ratios, variables
2. **Algebra** - equations, systems, functions, graphs
3. **Calculus intuition** - rates, derivatives, integrals, gradients
4. **Linear algebra** - vectors, matrices, dot products, bases
5. **Probability & information** - chance, Bayes, expectation, entropy

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- MDX lessons + KaTeX
- Manrope + Cursor marketing light/dark palette
- Local progress (`localStorage`) - no accounts, no AI tutor

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Content

Lessons live in `content/courses/`. Research notes are in each course's `_sources/` folder. See `AGENTS.md` for content rules (research first, no em dashes).
